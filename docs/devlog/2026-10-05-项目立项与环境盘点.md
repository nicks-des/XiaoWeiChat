  库 `lingxi`（utf8mb4）已建。

### 重大坑：本机代理 + schannel 吊销检查（记录 5 次失败根因）
1. vcpkg 默认读 **Windows IE 代理**（注册表 127.0.0.1:7890，clash 类软件）；
2. 所有 TLS 下载报 `curl (35) SSL connect error`——根因是 **schannel 的证书吊销检查
   （CRYPT_E_NO_REVOCATION_CHECK）** 经代理时无法完成；
3. 修复：系统 curl 一律加 **`--ssl-no-revoke`**；vcpkg 侧双管齐下——
   - 工具（cmake/ninja/powershell-core/7zip）**手动预下载**进 `downloads/`（文件名须与
     `scripts/vcpkg-tools.json` 的 archive 字段完全一致，vcpkg 会校验 sha512）；
   - **port 源码**走 `X_VCPKG_ASSET_SOURCES="x-script,curl --ssl-no-revoke -x http://127.0.0.1:7890
     -L --fail --retry 3 {url} -o {dst}"`（注意：x-script 模板是逗号分隔的**单个参数**，
     不能带尾部行为参数；且**工具下载不走资产缓存**，只有 port 走）；
4. `X_VCPKG_ASSET_SOURCES` 与 `HTTP_PROXY` 已写入 `tools/scripts/env.*` 备查。

### 其他坑
- **MySQL Connector C++ 8.3 缺 release 库**：`lib64/vs14/` 只有 debug 有 mysqlcppconn.lib，
  正常构建不可用 → 按 ADR-010 备选切到 **libmysqlclient C API**（已修订 ADR）；
- **CMake 4.x 与老配置的兼容**：Qt 5.12 等旧 config 可能触发 "< 3.5 兼容已移除"，
  统一加 `-DCMAKE_POLICY_VERSION_MINIMUM=3.5`；
- MySQL 宿主机服务实际监听 **3308**（非 3306），my.ini 确认；凭证未知，故本项目用专属 3316 实例。
