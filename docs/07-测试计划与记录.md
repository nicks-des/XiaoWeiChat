## 3. 用例设计模板

```markdown
### TC-M2-007 断线重连后消息不丢不重
- 前置：A、B 在线互为好友；B 本地 last_seq = 42
- 步骤：
  1. B 断网（禁用虚拟网卡）
  2. A 连续发送 10 条消息（seq 43~52 正常落库）
  3. B 恢复网络，触发重连与 SyncRequest
- 预期：
  1. B 重连成功后补拉 43~52 共 10 条，无空洞无重复
  2. SQLite 中 (conv_id, seq) 无重复主键冲突
  3. simbot 断言：B 收到的 seq 集合 == [43..52]
- 结果：☐ 通过 ☐ 失败 ｜ 实际：＿＿＿ ｜ 日期：＿＿＿ ｜ 执行人：＿＿＿
```

## 6. 压测基线（M2 建立，M8 终版）

| 指标 | M2 基线目标 | M8 终版目标 |
| --- | --- | --- |
| 并发长连接 | 1,000 | 3,000 |
| 消息速率 | 10 msg/s/连接（混合） | 20% 活跃连接 × 5 msg/s |
| 投递 P99（在线） | ≤ 200ms | ≤ 150ms |
| 丢失率（含弱网补拉后） | 0 | 0 |
| 服务端内存（ChatServer） | 稳态 ≤ 500MB | 稳态 ≤ 1GB |
| MySQL 慢查询 | 无 >100ms | 无 >100ms（explain 记录） |

报告模板：`docs/tests/压测报告-YYYYMMDD.md`（环境/参数/数据表/瓶颈分析/优化项）。

## 7. AI 专项测试策略（LLM 的不确定性处理）

- **结构断言而非内容断言**：Prompt 组装用快照测试（固定输入 → 断言 prompt 结构/分区/token 预算）；
- **世界书注入为纯函数**：算法输入输出确定 → GTest 覆盖触发/优先级/预算全分支；
- **Mock LLM Server**：本地起 Beast mock 返回固定 SSE 流，覆盖：正常/慢首包/中途断流/超长/脏 JSON；
- **好感度标记解析**：正则用例集（正常/缺失/多次/负值/越界）；
- **评测集**：维护 20 组「固定对话剧本」，人工评审 AI 回复质量（不阻断 CI，M7 起每轮记录）。
